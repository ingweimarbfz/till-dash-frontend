# Marca TillDash+

**Símbolo:** una "T" que es a la vez el rollo de la caja registradora (barra superior) y el tiquete que sale de ella
(con borde dentado), sobre un cuadrado redondeado paprika. El "+" ámbar arriba a la derecha es el valor agregado.

**Logotipo:** Till (carbón o blanco) + **Dash** (paprika) + "+" en exponente.

| Uso | Color | Hex |
|---|---|---|
| Principal (acciones, botones) | Paprika | `#E4572E` |
| Secundario (menú, estructura) | Carbón | `#1F2933` |
| Acento (promociones, destacados) | Ámbar | `#F2A541` |
| Éxito | Verde | `#2F9E6E` |
| Error | Rojo | `#D64545` |

**Tipografía:** Outfit (Google Fonts), geométrica, sobria y con carácter. El superadmin puede cambiarla en Apariencia.

Archivos: `tilldash-simbolo.svg` (vector), `tilldash-simbolo.png` (vista previa). Íconos de la app en `public/`.
